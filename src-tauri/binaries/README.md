# Binarios de producción

El instalador final incluirá aquí `yt-dlp.exe`, `ffmpeg.exe` y `ffprobe.exe`.

Durante desarrollo, la aplicación busca primero estos binarios junto al ejecutable y luego en el `PATH` de Windows. No se incluyen binarios de terceros en el repositorio para que sus versiones, licencias y actualizaciones se controlen explícitamente antes de empaquetar.
